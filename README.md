# Barrera Metálica con Rodillos — landing final

Proyecto Next.js preparado para GitHub + Vercel.

## Publicación
1. Suba **el contenido de esta carpeta** a la raíz del repositorio: `app/`, `public/`, `package.json`, `tsconfig.json`, `next-env.d.ts` y `README.md`.
2. Vercel debe detectar `Next.js` con `Root Directory: ./`.
3. El PDF de INVÍAS está en `public/docs/articulo-732-22-invias.pdf`.

- Nomenclatura: **Barrera Metálica con Rodillos**.
- CTA de header en una sola línea en desktop.
- Enlace de INVÍAS funcional.
