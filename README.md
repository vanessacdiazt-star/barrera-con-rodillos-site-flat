# Barrera Metálica con Rodillos

Landing page final en Next.js para `barreraconrodillos.com`.

## Cambio incorporado

El botón **Ver cómo funciona** del hero abre ahora un modal 16:9 con el video técnico optimizado (720p, ~7 MB). El video no se reproduce automáticamente y conserva controles nativos. Desde el modal se puede acceder a la explicación técnica de las etapas 01–02–03.

## Estructura

- `app/` — página y estilos.
- `public/assets/` — imágenes de la landing.
- `public/docs/` — documento INVÍAS.
- `public/video/funcionamiento-barrera.mp4` — video optimizado.

## Deploy

Sube el contenido de esta carpeta directamente a la raíz del mismo repositorio de GitHub conectado a Vercel. Vercel hará el redeploy automáticamente.
